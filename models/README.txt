u2netp.onnx  (U^2-Net-lite, "u2netp")
  Salient-object / person segmentation model used for the Sci-Fi background swap (segment.py).
  Source:  https://github.com/xuebinqin/U-2-Net   (ONNX export as distributed by https://github.com/danielgatis/rembg)
  License: Apache License 2.0
  Size:    ~4.6 MB, runs on the CPU through onnxruntime in about 0.3 s per photo.
  Optional: delete this file (or uninstall onnxruntime) and Sci-Fi simply uses its framed look instead.
